## Sobre o projeto

O **Sistema de Controle de Estoque** é um projeto desenvolvido para auxiliar pequenos negócios no gerenciamento de produtos, categorias e movimentações de estoque de forma otimizada e acessível.

A proposta é oferecer uma solução simples, organizada e intuitiva que facilite o controle das informações e reduza erros no gerenciamento manual, permitindo o gerenciamento dos dados dos produtos de maneira organizada.

---

## 🎯 Objetivo

Desenvolver um sistema web capaz de:

- Cadastrar e organizar produtos;
- Classificar produtos por categorias;
- Controlar a quantidade disponível em estoque;
- Definir estoque mínimo;
- Registrar entradas e saídas de produtos;
- Identificar a localização dos produtos;
- Facilitar a consulta das informações.
