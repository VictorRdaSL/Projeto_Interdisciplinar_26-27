<!--StartFragment--><html><head></head><body><h1>📦 Sistema de Controle de Estoque</h1>
<p>O <strong>Sistema de Controle de Estoque</strong> é um projeto desenvolvido para auxiliar pequenos negócios no gerenciamento de produtos, categorias e movimentações de estoque.</p>
<p>A proposta é oferecer uma solução simples, organizada e intuitiva para facilitar o controle das informações e reduzir erros no gerenciamento manual.</p><hr>

<h2>🎯 Objetivo</h2><p>Desenvolver um sistema web capaz de:</p><ul><li><p>Cadastrar e organizar produtos;</p></li><li><p>Classificar produtos por categorias;</p></li><li><p>Controlar a quantidade disponível em estoque;</p></li><li><p>Definir estoque mínimo;</p></li><li><p>Registrar entradas e saídas de produtos;</p></li><li><p>Identificar a localização dos produtos;</p></li><li><p>Facilitar a consulta das informações.</p></li></ul><hr>


<h2>👨‍💻 Desenvolvimento</h2>
<p>Projeto desenvolvido como parte das atividades acadêmicas da <strong>FATEC</strong>, com foco no desenvolvimento de uma aplicação web para gerenciamento de estoque.</p>
