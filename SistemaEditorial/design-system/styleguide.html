Manual de marca v1.1 · outubro 2026

Ordem que se lê.

Tokens e componentes do frontend do WareSys: CSS puro com custom properties, JavaScript vanilla só onde o CSS não resolve. Cada exemplo mostra o HTML para copiar. Fonte de verdade: o Manual de Marca v1.1.

Como usar

Quatro arquivos CSS na ordem abaixo e um JS opcional. Sem build, sem framework. Todas as classes começam com ws- e seguem BEM: bloco (.ws-btn), elemento (.ws-btn__seta), modificador (.ws-btn--primario); estados usam .is-* ou atributos ARIA.

<!-- No <head> (header.php comum) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap">
<link rel="stylesheet" href="design-system/css/tokens.css">
<link rel="stylesheet" href="design-system/css/base.css">
<link rel="stylesheet" href="design-system/css/layout.css">
<link rel="stylesheet" href="design-system/css/components.css">

<!-- Tema: o sistema já guarda em usuarios.tema -->
<html lang="pt-BR" data-theme="<?= htmlspecialchars($_SESSION['usuario_tema'] ?? 'claro') ?>">

<!-- No fim do <body> -->
<script src="https://unpkg.com/lucide@0.469.0/dist/umd/lucide.min.js"></script>
<script src="design-system/js/waresys.js" defer></script>

Não misture com o CSS antigo na mesma página.

O style_base.css antigo mexe em * e body, assim como o base.css. Migre uma tela por vez: a tela nova carrega só o design system.

Sem internet, a fonte e os ícones não carregam.

Para usar o XAMPP offline: baixe lucide.min.js (versão 0.469.0) para design-system/js/ e instale a Inter na máquina. O CSS já cai para a fonte do sistema se a Inter faltar.

Ícones

Lucide com traço 1,5, em Tiffany profundo (.ws-icone--destaque) ou cinza profundo (.ws-icone--texto). Inclua o script do Lucide pelo CDN e escreva <i data-lucide="nome">; o waresys.js troca pelo SVG com o traço certo. Ícone decorativo leva aria-hidden (o waresys.js já põe); botão só com ícone leva aria-label.

Campos

Versão acessível aprovada: fundo branco, borda #7A8C99 (3:1 contra o fundo) e foco em Tiffany profundo. Todo campo tem <label>; ajuda e erro ligados por aria-describedby.

Input, select, textarea, ajuda, erro

ISBN-13. Pode ficar vazio até a Catalogação.

Dígito verificador não confere. Para este número, o último dígito é 4.

Texto livre. Fica no livro, não na etapa.

Etiquetas e status

Etiqueta é rótulo, sem cor de status. Status é ponto + texto, sempre juntos, e só na coluna ou área de status. Concluído e cancelado usam etiqueta neutra.
